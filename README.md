# Пошук підрядка у двох статтях

Запуск із цієї теки: `python benchmark.py` (Python 3.10+, без сторонніх бібліотек). Алгоритми й таблиці префіксів/зсувів реалізовані у [search.py](search.py). Пошук повертає позицію першого збігу, –1 за його відсутності та 0 для порожнього шаблону.

Використано саме файли із завдання: [стаття 1, Windows-1251](https://drive.google.com/file/d/18_R5vEQ3eDuy2VdV3K5Lu-R-B-adxXZh/view) та [стаття 2, UTF-8 з BOM](https://drive.google.com/file/d/18BfXyQcmuinEI_8KDSnQm4bLx6yIFS_w/view). Копії у `data/` збережені в початкових кодуваннях. Розмір після декодування та нормалізації переносу рядка — 12 658 та 17 590 символів.

## Умови досліду

Наявні шаблони: «працює як лінійний пошук» (позиція 6432) і «редагувати дані графу» (8933). Для відсутнього шаблону замінено останній символ на Ω: довжина незмінна, повного збігу немає. Кожен результат перед вимірюванням звірено з `str.find`. Враховано підготовку шаблону, але не читання файлів. Час — медіана семи серій `timeit` по 20 пошуків, мс на виклик. CPython 3.12.3, Linux (WSL).

## Висновки

За однакової ваги двох запитів на першому тексті найшвидшим був Боєр–Мур: середній час 0,144 мс. На другому він теж переміг — 0,228 мс. За всіма чотирма сценаріями середні становили відповідно **0,186; 0,686; 1,957 мс**. [Повна точність та індекси](results.csv).

Правило поганого символу дозволяло пропускати відразу кілька позицій. КМП послідовно опрацьовує символи та має гарантований час O(n+m), а Рабін–Карп на кожному зміщенні оновлює хеш і перевіряє збіги. Відсутні шаблони вимагали перегляду тексту до кінця. Перевага Боєра–Мура стосується саме цих текстів, шаблонів і реалізацій; для коротких чи сильно повторюваних шаблонів співвідношення може змінитися.
